
MAX BANK - Banking Application

A command-line banking application built with Python and PostgreSQL, using object-oriented programming(OOP) principles.

Features

* Create a bank account
* Log in securely using account credentials
* Check account balance
* Deposit and withdraw funds
* Transfer funds between accounts
* View transaction history
* Store account and transaction data in PostgreSQL

Technologies Used

* Python
* PostgreSQL
* psycopg
* python-dotenv
* SQL

Project Structure

* BankingV2.py - Main banking application and user interaction
* Database.py - Database connection and database operations
* Test.py - Testing and connection checks

Setup

1. Clone this repository.
2. Install the required Python packages.
3. Create a PostgreSQL database and configure the required tables.
4. Create a .env file containing your database connection settings.
5. Run the application with Python.

Important: Never commit your .env file or expose your database password.
